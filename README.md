# Color Jar — MVP prototype

3色（75% / 20% / 5%）のカラーパレットを小瓶として作成・保存・閲覧する、ブラウザ用のプロトタイプです。

## まず試す

### Mac
1. このフォルダを開く
2. `start.command` をダブルクリック
3. ブラウザで `http://localhost:8000` が開きます

初回だけ macOS に実行を止められた場合は、ターミナルでこのフォルダへ移動し、次を実行してください。

```bash
chmod +x start.command
./start.command
```

### ターミナルから起動する場合

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 保存について

作成したパレットはブラウザの `localStorage` に `color-jar-palettes-v1` というキーで保存します。同じブラウザ・同じURLで開けばページを閉じても残ります。

ブラウザのサイトデータを削除した場合や、別ブラウザ・別端末では自動的には引き継がれません。

## 現在入っている機能

- 3色の作成（ベース75%、サブ20%、アクセント5%）
- カラーサークル
- 彩度・明度の四角いフィールド
- H / S / V の3本のスライダー
- HEX直接入力・コピー
- 瓶の名前
- 75 / 20 / 5 のリアルタイム瓶プレビュー
- 保存時に75% → 20% → 5%の順で砂を注ぐアニメーション
- LocalStorageへの保存
- コレクション棚
- 詳細表示
- 編集・複製・削除
- スマートフォン向けレスポンシブ

## ファイル

- `index.html` — 画面構造
- `styles.css` — UI・瓶・砂・アニメーション
- `app.js` — 色変換、操作、LocalStorage、画面遷移

外部ライブラリは使っていません。まず体験を確認し、その後必要に応じてReact/TypeScript版へ移行できる構造にしています。
